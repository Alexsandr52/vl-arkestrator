# 0001. Руки удерживаются всю сессию, задачи не создают новых владельцев

Статус: принято пользователем 24.11.2026.

## Контекст

В GR00T-pickup-bottle один процесс выполняет одну попытку. В конце он удерживает руки, пока
оператор не подтвердит свободную траекторию (`release_supported.json`). Для оркестратора это
значило бы клик оператора после каждой команды и повторный захват рук перед каждой задачей.

## Решение

- Демон один раз за сессию создаёт владельца DDS и рук (`SessionPump` через `G1Session`) и
  держит его до конца сессии.
- Между командами руки стоят в позе `ready`.
- Ходьба идёт только внутри mobile segment (`begin_mobile_hold`/`finish_mobile_hold`). Позы рук
  меняются только вне сегментов.
- Отдача рук заводскому контроллеру происходит только при завершении сессии или после STOP и
  только по существующему протоколу с подтверждением. В панели это два флажка: «путь рук
  свободен» и «предмет поддержан или его нет».

## Следствия

- Нужна правка rearm в `xr_full.py` (см. docs/architecture.md), иначе VLA запускается один раз на worker.
- Камера работает всю сессию: удержание требует свежего кадра.
- Пока руки удерживаются, пульт заблокирован проверкой стиков. Поэтому Teach делается до сессии.
