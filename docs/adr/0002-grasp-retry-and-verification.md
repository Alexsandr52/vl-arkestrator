# 0002. Проверка захвата и повтор

Статус: принято (запрос пользователя 24.11.2026: «VLA работает не на 100%, нужна проверка
захвата и повтор»).

## Решение

Попытка состоит из шагов: `prepare_grasp` (открыть кисть, стартовая поза, новая базовая линия
тактильных датчиков) → VLA до условия профиля (контакт или время) → scripted-хвост профиля →
проверка.

Проверка задаётся в профиле (`grasp.verify`):
- **tactile** — VLA закончилась на измеренном контакте, и хвост сообщает давление или упор
  пальцев. Кулак без давления означает, что рука пуста.
- **visual** — на `visual_needed` из `visual_votes` свежих кадров предмета нет на прежнем месте
  стола (та же точка xy и высота), и VLM не отрицает, что робот его держит.

При промахе: раскрыть кисть → отвести руку вверх и назад → переизмерить предмет → при сдвиге
подшагнуть (руки в `ready`) → следующая попытка. После `max_attempts` (по умолчанию 3,
настраивается) задача заканчивается восстановимой ошибкой `grasp_failed`: поза ready → шаг
назад → «Не смог взять …» → IDLE.

## Следствия

- `max_attempts` — новый лимит, но он часть запрошенной функции повтора.
- У бутылки неудачное дожатие — это STOP, в оркестраторе это промах (своя копия кода с
  source-pin; P4).
- `physical_grasp_success` в журнале ставит только оператор. Проверка оркестратора — это
  «подтверждено датчиками», а не физический факт.
