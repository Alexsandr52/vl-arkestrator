# 0003. Один клиент для двух контрактов π0.5

Статус: принято.

## Контекст

Серверы бутылки и коробки совпадают по кадрированию: 4 байта длины + npz с `image_rgb_jpeg`,
`state[28]` и `request_id`; ответы — строки `READY`/`RESULT`. Поля ответов различаются:

| | бутылка (`lerobot_stdio_v1`) | коробка (`box_stdio_v1`) |
|---|---|---|
| порядок | `left_arm_0..right_ee_6` (по индексу = `JOINT_NAMES`) | `joint_names` = `JOINT_NAMES` |
| хэш кадра | sha256 байтов JPEG | sha256 декодированного RGB (cv2) |
| горизонт | `horizon` (50) | `actions` 10 + `full_actions` 50 |
| признак без моторов | `motor_commands_sent: false` | `robot_commands_sent: 0` |
| задача | `task` в RESULT | фиксирована «Pick up box» |

Контракты в коде: `lerobot_stdio_v1` (оригинальный сервер бутылки), `arkestrator_stdio_v1`
(наш сервер), `box_stdio_v1` (оригинальный сервер коробки).

## Решение

- Внутренний порядок — именованный `arkestrator/vla/contract.py::JOINT_NAMES`, радианы,
  абсолютные позиции, 15 Гц.
- `StdioPolicyClient` проверяет каждый ответ по своему контракту и при любом расхождении
  отклоняет его, ничего не исправляя.
- Профиль задаёт `execute_steps`: у коробки 10 из чанка 50, у бутылки 50. `SessionPump` держит
  один горизонт на сессию, 50.
- `Prediction.actions` содержит только исполнимые шаги (`execute_steps`), полный чанк лежит в
  `Prediction.chunk`.
- После любой ошибки посреди обмена клиент помечается сломанным и закрывается (`request_id`
  больше не синхронен), пул загружает модель заново. Кадр проверяется на 1280×720 по заголовку
  JPEG до отправки.
- Свой обобщённый сервер (`vla_servers/pi05_stdio_server.py`, P1) работает по контракту
  `arkestrator_stdio_v1`: протокол бутылки плюс обязательные в READY поля `task`, `image_key`,
  `noise_seed` и `chunk_size ≥ horizon`. Сервер, запущенный с чужим профилем, отклоняется при
  загрузке. Для коробки это снимает требования оригинального сервера (пользователь `ildar`,
  18 ГиБ свободной VRAM, `training.lock`); seed 123 на каждый запрос сохраняется.
- Совпадение действий с оригинальными серверами проверяется офлайн на записанных npz.
  Оригиналы остаются запасным вариантом: `lerobot_stdio_v1` для бутылки и `box_stdio_v1` для
  коробки (проверки как в `model_box_policy.Predictor`: seed, `randomness_mode`, `schema`).
